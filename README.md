# Ginance
这是我用来**锻炼**自己技术做的项目，这个项目的目标旨在实现一个对自己全部资产的图表化显示，我现在期望囊括的资产有加密资产，美股，A股(maybe),以及黄金其他较主流的资产。

我期望实现的功能有：
- 实时展示资产变化情况(动态展示的图表)
- 用户只需要导入持有的份数即可
- 对用户数据的完全保密是我所期望的也是必须实现的，但是这个应该是后面会实现的
- 用户登录

目前需要实现的有：
- 一个demo来实现数据的实时变化


全部计划：
### 阶段一：核心功能的“单机版” (验证想法)

* **【步骤 1：获取市场数据】**
    * **任务：** 用 `net/http` 包请求 API，获取 BTC 价格并打印在控制台。
* **【步骤 2：计算资产价值】**
    * **任务：** 在代码中硬编码持仓，计算并打印总资产价值。

### 階段二：成為一個“API 服務” (引入 Gin)

* **【步骤 3：创建你的第一个 API】**
    * **任务：** 引入 `Gin`，创建 `GET /api/portfolio` 路由，返回 JSON 响应。

### 阶段三：持久化与多用户基础 (引入数据库)

* **【步骤 4：设计和连接数据库】**
    * **任务：** 安装 `PostgreSQL`。设计 `users` 表和 `assets` 表（带 `user_id` 外键）。使用 `GORM` 连接数据库。
* **【步骤 5：实现注册功能】**
    * **任务：** 创建 `POST /api/register` 接口。使用 `bcrypt` 哈希密码后存入数据库。
* **【步骤 6：实现登录与 JWT】**
    * **任务：** 创建 `POST /api/login` 接口。验证密码，成功后使用 `golang-jwt/jwt` 生成 JWT 返回。

### 阶段四：安全与授权 (保护你的数据)

* **【步骤 7：编写认证中间件】**
    * **任务：** 编写 `Gin` 中间件，检查 JWT。如果有效，将 `user_id` 存入 `Gin` 上下文 (`c.Set`)。
* **【步骤 8：改造 API 实现授权】**
    * **任务：** 将中间件应用到需保护的路由。修改处理器逻辑，从上下文 (`c.Get`) 获取 `user_id`，并使用 `WHERE user_id = ?` 查询数据库。

### 阶段五：性能优化 (引入 Redis 缓存)

* **【步骤 9：引入 Redis 缓存】**
    * **目标：** 缓存高频访问的数据（如第三方金融 API 的价格）。
    * **任务：** 学习使用 `go-redis/redis` 客户端。修改你的“获取价格”逻辑：**先查 Redis**，如果 Redis 中没有（或已过期），**再请求第三方 API**，并将结果存入 Redis（例如设置 10 秒过期）。

### 阶段六：实现“实时” (WebSocket 与并发)

* **【步骤 10：引入 WebSocket】**
    * **任务：** 使用 `gorilla/websocket` 库，创建一个 `GET /ws` 路由（受认证中间件保护），将 HTTP 连接“升级”为 WebSocket 连接。
* **【步骤 11：并发与广播 (Hub & Goroutines)】**
    * **任务：**
        1.  创建一个“Hub”对象管理所有 WebSocket 连接。
        2.  启动一个单独的 `Goroutine`（`PriceTicker`）定时（如每 10 秒）**从 Redis 中获取**最新的市场价格。
        3.  `PriceTicker` 通过 `Channel` 通知 Hub。
        4.  Hub 收到通知后，将新价格广播给所有连接的客户端。

### 阶段七：容器化部署 (Docker)

* **【步骤 12：编写 Dockerfile】**
    * **目标：** 将你的 Go 应用打包成一个标准镜像。
    * **任务：** 学习编写 `Dockerfile`，使用“多阶段构建”（Multi-stage build）来创建一个体积小、安全（不含 Go 源码）的最终镜像。
* **【步骤 13：使用 Docker Compose 编排】**
    * **目标：** 一键启动整个应用（Go + 数据库 + 缓存）。
    * **任务：** 编写 `docker-compose.yml` 文件，定义三个服务：`ginance-app`（使用你的 Dockerfile）、`postgres-db`（使用官方镜像）、`redis-cache`（使用官方镜像）。
